# 🚌 BusGo – Online Bus Booking System

BusGo is a responsive frontend web application designed to demonstrate an online bus booking experience. Users can search available sample bus routes, compare ticket prices, select seats, enter passenger details, and generate a demo booking ticket.

## ✨ Features

- Responsive and modern user interface
- Search buses by source and destination
- Select a journey date
- View sample bus routes and details
- Sort buses by ticket price
- Interactive seat selection
- Maximum of 6 seats per booking
- Automatic total price calculation
- Passenger details form with validation
- Demo ticket generation
- Print-friendly ticket layout

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactions

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the BusGo folder in VS Code.
3. Open `index.html` in your browser.
4. Search for a sample bus route.
5. Select a bus and choose seats.
6. Enter dummy passenger details to generate a demo ticket.

## ⚠️ Important Note

This is an educational frontend demonstration project. Bus routes and seat availability are sample data. It does not provide real-time bus inventory, actual reservations, online payments, or backend database storage. Use dummy passenger details only.
